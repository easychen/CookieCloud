🔑 第一步：创建你的安全密钥

CookieCloud 使用 HMAC 密钥来保护数据传输。你只需要点击"随机生成"按钮，系统会自动帮你创建一个安全的密钥。

💡 什么是 HMAC 密钥？

类似于你的"钥匙"——只有持有同一把钥匙的浏览器插件才能读写你的 Cookie 数据。Key ID 是钥匙的名字，Secret 是钥匙的内容。

    🌐 安装浏览器插件

    安装 CookieCloud 浏览器扩展，然后将下方信息填入插件设置页：

    ⬇️ 下载本地插件（最新） 🟢 Chrome 应用商店 🔵 Edge 应用商店

    下载后请先解压 zip，再在 chrome://extensions / edge://extensions 开启开发者模式并点击“加载已解压的扩展程序”。

    📋 插件填写模板

    安装插件后，打开插件设置页，按下方信息逐项填入：

    Server Address 保存配置后自动显示
    Auth Key ID 保存配置后自动显示
    Auth Secret ⚠️ 填入你在第一步设置的 Secret（本页不显示明文）
    Encryption Algorithm AES-256-GCM (PBKDF2)
